# 📖 Книга нашей семьи

Интерактивное веб-приложение для создания и просмотра семейной книги с реалистичной анимацией перелистывания страниц.

## ✨ Особенности

- 📱 **Адаптивный дизайн** — работает на десктопах, планшетах и телефонах
- 📖 **Реалистичное листание** — эффект настоящей книги с помощью PageFlip
- 🎮 **Множество способов навигации**:
  - ⌨️ Стрелки клавиатуры (← →)
  - 🖱️ Двойной клик мышью
  - 🎡 Колёсико мыши
  - ⌨️ Home / End для быстрой навигации
- 🎨 **Красивый дизайн** — деревянный фон и винтажный стиль

## 🚀 Быстрый старт

### Локально на компьютере:
1. Клонируйте репозиторий:
```bash
git clone https://github.com/Zakhar9620/Family-story.git
cd Family-story
```

2. Откройте `index.html` в браузере:

```bash
start index.html             # Windows
xdg-open index.html         # Linux
```

### Online:
- Откройте в браузере: `https://Zakhar9620.github.io/Family-story`
- Используйте VS Code Live Server расширение

## 🎯 Как использовать

### Добавление фотографий:
1. Откройте `index.html` в текстовом редакторе
2. Найдите блок с классом `photo-frame`
3. Замените текст "Фото" на HTML для вашего изображения:
```html
<div class="photo-frame">
    <img src="path/to/your/photo.jpg" alt="Описание фото" style="width: 100%; height: 100%; object-fit: cover;">
</div>
```

### Добавление видео:
1. Найдите блок с классом `video-box`
2. Вставьте встроенное видео с YouTube:
```html
<div class="video-box">
    <iframe width="100%" height="100%" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allowfullscreen></iframe>
</div>
```

### Добавление текста:
Просто отредактируйте текст внутри `<p>` тегов:
```html
<p>
    Здесь будет размещена история вашей семьи.
</p>
```

### Добавление QR-кода:
Используйте генератор QR-кодов (qrcode.com) и вставьте:
```html
<div class="qr-box">
    <img src="path/to/qr.png" alt="QR код">
</div>
```

## ⚙️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — современные стили и адаптивность
- **JavaScript (Vanilla)** — управление логикой
- **PageFlip** — библиотека для анимации листания (из CDN)
- **Google Fonts** — красивые шрифты (Cinzel, Cormorant Garamond)

## 🎮 Управление

| Действие | Способ |
|----------|--------|
| Следующая страница | → Клавиша, Двойной клик справа, Колесо вниз |
| Предыдущая страница | ← Клавиша, Двойной клик слева, Колесо вверх |
| На начало | Home |
| В конец | End |

## 🌐 Развертывание на GitHub Pages

1. Убедитесь, что репозиторий публичный
2. Перейдите в **Settings** → **Pages**
3. Выберите ветку `main` как источник
4. Сохраните и получите ссылку (обычно `https://USERNAME.github.io/Family-story`)
